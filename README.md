# US data centers

An interactive map and chat assistant for exploring existing, proposed and projected data centers in the United States together with their environmental and equity setting. The app is built on [glen](https://github.com/SchmidtDSE/glen) from [glen-template](https://github.com/SchmidtDSE/glen-template) and runs at https://datacenters.nrp-nautilus.io.

## Data

Data center layers come from the `public-datacenters` collection of the NRP public data catalog:

- FracTracker Alliance's U.S. Data Centers Tracker, with existing, permitted and proposed facilities and the community response to them;
- FracTracker's list of local data center moratoriums, bans and zoning restrictions;
- Epoch AI's database of large AI data centers and their building and equipment footprints;
- PNNL's IM3 Open Source Data Center Atlas of existing facilities and its projected data center sites to 2035 under 20 growth and siting scenarios.

Context layers include the CDC Social Vulnerability Index 2022 by tract and county, ACS 2020–2024 block-group income and poverty, historical redlining, population density, EPA community water system service areas, watersheds, wetlands, FEMA flood hazard zones, sea level rise, PAD-US protected areas, critical habitat and land cover.

Each source carries its own licence and citation in its STAC collection.

## Repository structure

```
index.html              HTML shell that loads glen core from the CDN
layers-input.json       map layers and app settings, generated by scripts/build-layers.py
scripts/build-layers.py source of truth for the layer list
system-prompt.md        domain guidance for the chat assistant
k8s/                    Kubernetes manifests for the NRP deployment
```

Edit `scripts/build-layers.py` and run `python3 scripts/build-layers.py` to change layers.

## Deployment

The app runs in the `schmidtdse` namespace on the National Research Platform. The pod clones `main` at startup, so push first and then restart:

```bash
git push
kubectl apply -f k8s/
kubectl rollout restart -f k8s/deployment.yaml
kubectl rollout status  -f k8s/deployment.yaml
```

See `AGENTS.md` for configuration details.
